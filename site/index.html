How to read this

Match audit. Euclid's catalogue names a Gaia counterpart for each star. We redo the match independently (Gaia position moved by its proper motion to the tile's coordinate epoch, nearest Euclid source within 0.5 arcsec) and count where the two differ.

Position. Euclid position minus propagated Gaia position. Euclid's astrometry is calibrated on Gaia, so a tile's median offset measures calibration, not independent agreement. Euclid publishes no per-source position error, so an outlier is a star beyond 5 times the scatter measured for its brightness.

Brightness. A colour relation from Gaia G and BP−RP to Euclid VIS is fitted per tile; the residual about it is the product. It tests star-to-star consistency, not the absolute level.

Outliers are flags, not findings. Each carries context from both catalogues (poor Gaia fit, no Gaia proper motion, Euclid says extended) and nothing here has been checked by eye unless it says so.
